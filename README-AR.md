# CodeDock — محرّر مواقع محلي

## التشغيل على Windows

1. ثبّت Node.js بالإصدار 22 أو أحدث من https://nodejs.org إن لم يكن موجودًا.
2. فك ضغط ZIP بالكامل.
3. شغّل `Start-Windows.bat` واترك نافذته مفتوحة.
4. افتح http://localhost:3000 في Chrome أو Edge. إذا فتحت الصفحة قبل تشغيل الخادم، حدّثها.

لا يحتاج المشروع إلى `npm install`، ولا يستخدم مكتبات تُحمَّل من الإنترنت. التحرير والمعاينة يعملان دون إنترنت؛ تسجيل الدخول والنشر يحتاجان اتصالًا.

على macOS أو Linux: افتح الطرفية داخل المجلد، نفّذ `node server.mjs`، ثم افتح نفس الرابط.

## ماذا يتضمن؟

- واجهة عربية متجاوبة، محرّر نصّي باتجاه يسار إلى يمين وأرقام أسطر.
- HTML وCSS وJavaScript وXML؛ إضافة ملفات وحذفها وتسميتها، ودعم أسماء مجلدات مثل `pages/about.html`.
- استيراد ملفات نصية، تنزيل ملف منفرد، وتنزيل المشروع كاملًا بصيغة ZIP.
- حفظ تلقائي على المتصفح نفسه باستخدام localStorage؛ الحفظ ليس حسابًا سحابيًا ولا نسخة احتياطية. حذف بيانات المتصفح يحذف المسودة.
- مشاركة ZIP عبر نافذة مشاركة الجهاز إن كان المتصفح يدعمها؛ وإلا يُنزّل الملف لإرساله يدويًا عبر واتساب أو البريد.
- تشغيل الموقع على خادم معاينة منفصل على localhost:3001، مع اختيار ملف HTML وبعرض هاتف أو عرض كامل، أو فتحه في تبويب جديد.
- تسجيل دخول OAuth بحساب GitHub، عرض اسم المستخدم، وإنشاء مستودع عام جديد ورفع الملفات ثم تفعيل GitHub Pages وإظهار رابط الموقع.
- زر للتحقق من اكتمال بناء Pages؛ ظهور الرابط لا يعني أن الموقع جاهز فورًا.

اختصارات: Ctrl+Enter للتشغيل، Ctrl+S للحفظ، Tab لإضافة مسافتين.

## إعداد GitHub — مرة واحدة لمشغّل البرنامج

1. افتح https://github.com/settings/developers
2. اختر **OAuth Apps → New OAuth App**.
3. Application name: `CodeDock Local`.
4. Homepage URL: `http://localhost:3000`.
5. Authorization callback URL: `http://localhost:3000/auth/callback`.
6. سجّل التطبيق، وانسخ Client ID وأنشئ Client Secret.
7. انسخ `.env.example` إلى ملف اسمه `.env` بجانب `server.mjs`:

```env
GITHUB_CLIENT_ID=ضع_Client_ID_هنا
GITHUB_CLIENT_SECRET=ضع_Client_Secret_هنا
PORT=3000
PREVIEW_PORT=3001
```

8. أغلق الخادم وأعد تشغيله، ثم اضغط **تسجيل الدخول بـ GitHub**.

مفتاح Client Secret مخصص للخادم فقط؛ لا تشاركه، ولا ترفعه إلى GitHub، ولا تضعه داخل HTML أو JS. ملف `.gitignore` يستثني `.env` من Git.

## نشر موقع

1. احتفظ بصفحة البداية باسم `index.html` في الجذر.
2. استخدم روابط ملفات نسبية: `style.css` و`./script.js`، أو `../style.css` من صفحة داخل مجلد. المسارات التي تبدأ بـ `/` قد لا تعمل تحت عنوان مستودع GitHub Pages.
3. سجّل الدخول واضغط **نشر على GitHub**.
4. اكتب اسم مستودع جديد، ووافق على أن الملفات والموقع ستكون عامة.
5. بعد الرفع يظهر رابط المستودع ورابط Pages. انتظر بناء GitHub ثم اضغط التحقق.

كل عملية تنشئ مستودعًا جديدًا؛ لا يعدّل البرنامج مستودعًا موجودًا. إذا كان الاسم مستخدمًا اختر اسمًا آخر. إذا حدث فشل بعد إنشاء المستودع، يعرض البرنامج رابط المستودع الذي أُنشئ لمراجعته؛ لا يحذفه تلقائيًا. الحسابات أو المؤسسات التي تمنع Pages قد ترفض التفعيل.

يطلب OAuth صلاحية `public_repo` لإدارة المستودعات العامة. تُحفظ رموز الدخول في ذاكرة الخادم فقط، والكوكي HttpOnly وSameSite؛ تنتهي الجلسة خلال 8 ساعات أو عند إيقاف الخادم. للخروج الكامل من صلاحيات التطبيق، ألغِ وصوله من إعدادات GitHub → Applications.

## حدود النسخة

- المشروع محرّر للواجهات الأمامية، وليس لتشغيل PHP أو Python أو npm أو قواعد بيانات. XML ملف بيانات قابل للتحرير ويستطيع JavaScript قراءته.
- لا يتضمن تلوينًا نحويًا أو IntelliSense؛ المحرّر نصّي مع أرقام أسطر.
- حتى 50 ملفًا و2 MB من النصوص في المشروع. استيراد الملفات يدعم HTML/CSS/JS/XML فقط، ولا يستورد ZIP أو الصور.
- المعاينة معزولة؛ JavaScript العادي والوحدات وقراءة ملفات XML متاحة، لكن localStorage والكوكيز وبعض الوظائف التي تحتاج أصلًا ثابتًا داخل الموقع المعروض محظورة. المسارات النسبية تعمل. الروابط إلى موارد الإنترنت تحتاج اتصالًا وقد تخضع لـCORS.
- روابط المعاينة محلية، تنتهي بعد ساعة أو عند إغلاق الخادم. شارك ZIP أو رابط GitHub Pages مع الآخرين.
- يستمع الخادم على جهازك فقط. لا تحوّله لخدمة عامة بمجرد تغيير عنوان الاستماع: الاستضافة العامة تحتاج HTTPS وضبط عناوين OAuth وCSRF ووسيلة جلسات دائمة وحدود استخدام. هذه نسخة تشغيل محلي.
- محرّر CodeDock يحتاج Node.js لتسجيل الدخول والنشر؛ GitHub Pages يستضيف المواقع التي تنتجها، ولا يشغّل خادم المحرّر نفسه.

## الملفات

- `server.mjs`: الخادم، OAuth مع state وPKCE، API النشر، ومعاينة معزولة.
- `public/index.html`: الواجهة.
- `public/style.css`: التصميم والتجاوب.
- `public/app.js`: التحرير والحفظ والمشاركة وتصدير ZIP.
- `test.mjs`: اختبارات حدود الملفات ورفض الطلبات الخارجية والمعاينة ورفض OAuth غير الصحيح.

## التحقق

نفّذ `npm test`. اجتازت الاختبارات الأربعة، وتم فحص صياغة JavaScript. لم يُختبر OAuth أو الرفع بحساب GitHub حقيقي لعدم توفر بيانات تطبيق OAuth، ولم تكتمل تجربة متصفح آلية لعدم توفر Chromium في بيئة البناء.
